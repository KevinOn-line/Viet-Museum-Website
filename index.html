About This Website

An interactive exploration of history. This website was created to provide an engaging way to learn about Vietnamese history. Each timeline event is represented by a card that can be clicked for more details, and the background features a dynamic 3D visual created with Three.js to enhance the user experience. The side text is a summary of the major event, and clicking the card will reveal more information. Please Note that this website may not be fully optimized for mobile devices, and is best viewed on a desktop or laptop for the full experience. However, we are continuously working on improving the design and functionality to make it more accessible for all users. Additionally, this website is a work in progress, and we plan to add more events and features in the future to provide a richer learning experience about Vietnamese history. Along with that, we are also working on optimizing the performance and responsiveness of the website to ensure a smooth and enjoyable user experience across all devices. [Insert ]
